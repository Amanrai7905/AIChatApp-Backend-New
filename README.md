# AI Chat App - Backend

## Overview

This is the ASP.NET Core 8 Web API backend for the AI Chat application.

## Features

- User Registration
- User Login (JWT Authentication)
- AI Chat API
- Conversation History
- PostgreSQL Database
- Entity Framework Core
- Docker Support

## Technologies

- ASP.NET Core 8
- Entity Framework Core
- PostgreSQL
- JWT Authentication
- Docker
- Npgsql

## Run Locally

```bash
docker compose up --build
```

Backend:

http://localhost:5000/swagger
